# ANALYSIS — transform ablation + camera-height sweep (K1 / NaVILA)

Generated by `receipts/analysis/analyze_sweep.py` from the committed per-episode
receipts in `receipts/sweep_measurements/` and `receipts/baseline_full_14498/`.
Re-run with `python receipts/analysis/analyze_sweep.py` — no external data needed.

**Analysis plan:** pre-registered in `receipts/PRE_REGISTRATION.md`. The original
primary test (McNemar, paired) was invalidated by that document's own determinism
gate; unpaired two-proportion tests + binomial CIs were substituted on 2026-07-27,
before any arm data was inspected. See the AMENDMENT section of the pre-registration.

**Driver confound:** every sweep arm ran on NVIDIA **580.173.02**; the `full_14498`
baseline ran on **580.159.03** (purged, unobtainable). Any sweep-vs-baseline contrast
spans a driver change and is an UPPER BOUND on reproducibility, not a noise floor.
The within-sweep `stretchA` vs `stretchB` contrast is the clean same-driver noise floor.

of the episode list, which land on record indices 0..488 with gaps. Arms are therefore

## 2. Resolution floor (what this design could ever have detected)

At a base rate of ~18% SR, alpha=0.05, power=0.80, unpaired:

- n=300 vs n=300: minimum detectable difference ~**8.7 pp**
- n=200 vs n=200: minimum detectable difference ~**10.7 pp**
- n=300 vs n=200: minimum detectable difference ~**9.8 pp**

Every observed contrast below is smaller than these floors unless flagged otherwise.
This is a pre-registered limitation, not a post-hoc excuse: the design was powered only
for large effects, and the pre-registration states a null was an acceptable outcome.

## 4. Height trend test (Cochran-Armitage)

- **SR vs camera height (m):** z = +0.828, p = 0.408 -> NO monotone trend
- **OS vs camera height (m):** z = -1.073, p = 0.283 -> NO monotone trend

The trend test asks whether SR/OS move monotonically with camera height. It does NOT
test for a non-monotone optimum; the observed h095 peak is examined in section 3.3 as a
single pairwise contrast and must be read against the Holm-adjusted p-value there.

## 6. What the numbers support

1. **Noise floor.** Two identical stretch runs on the same driver differ by 1.0 pp SR (16.0 vs 15.0), p_fisher = 0.822. Run-to-run variation of this size is expected and is the yardstick every other contrast must clear.
2. **Transform ablation: NULL.** No transform contrast survives Holm correction on SR. This is the pre-registered expected outcome, not a failure of the experiment.
3. **Height sweep: NULL on every pairwise contrast** after Holm correction. The h095 peak is within the run-to-run noise established in (1) and must NOT be reported as an optimum without a replication arm.
4. **Reproducibility across the driver change** is reported in 3.4 as an upper bound. It cannot be separated from run-to-run nondeterminism with the data in hand.
